# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and help people learn. This is a
first machine-learning project, and beginners are very welcome here.

Harassment, insults or personal attacks are not acceptable in issues,
pull requests, discussions or any other project space.

## Reporting

If something feels wrong, open an issue or contact the maintainer via GitHub.
Reports will be handled respectfully and as privately as possible.
