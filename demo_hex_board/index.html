Export works for any loaded or live game. Imported files use the same schema as training data and can be replayed or fed back into dataset tooling.

Demo notes

  • Replay saved game disables agent dropdowns so old logs are not confused with new matches.
  • Start new live game disables replay selection and requires the optional Python backend.
  • Live backend logs include move timings and are saved under logs/games/demo_live.
  • Agent descriptions below each dropdown show who created the agent and why it was made.
  • Exported game sessions use the exact JSON schema used for training data, so they can be re-imported for replay or reused for dataset building.
